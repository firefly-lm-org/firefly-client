# Firefly Client - GPU Requirements
# Use this when your machine has an NVIDIA GPU with CUDA support.
#
# ============================================================
# IMPORTANT: Install in the correct order, or bitsandbytes will fail.
# ============================================================
#
# Step 1: Install PyTorch with CUDA 12.1 support FIRST
#   (Do NOT use the default PyPI index — it ships CUDA 12.x-compatible wheels
#    but may not match your driver. Use the official PyTorch index.)
#
#   pip install torch==2.4.0 --index-url https://download.pytorch.org/whl/cu121
#
# Step 2: Install the remaining dependencies (use a Chinese mirror is fine)
#   pip install -r requirements-gpu-rest.txt
#
# Step 3: Verify GPU access
#   python -c "import torch; print('GPU:', torch.cuda.get_device_name(0))"
#   python -c "import torch; assert torch.cuda.is_available()"
#
# ============================================================
# Compatibility matrix (tested with Firefly v0.3):
#   torch==2.4.0 + cu121
#   transformers==4.44.0
#   peft==0.12.0
#   trl==0.8.0
#   bitsandbytes==0.50.0
#   accelerate==1.14.0
#   tokenizers==0.19.1
#   huggingface_hub==0.36.2
# ============================================================
