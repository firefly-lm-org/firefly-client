# 萤火虫大模型 Firefly LM — 隐私政策

**生效日期**：2026-07-24
**最后更新**：2026-07-24

感谢你选择参与萤火虫大模型（Firefly LM）项目。本项目是一个开源的分布式志愿算力平台，旨在通过汇聚全球闲置算力，共同建设和维护公共智能基础设施。

我们高度重视你的隐私和数据安全。本隐私政策说明了我们在你使用萤火虫节点客户端（以下简称"客户端"）时收集、使用和保护个人信息的方式。

---

## 1. 我们收集的信息

### 1.1 必要信息（用于算力调度与贡献结算）

为了将你的设备接入分布式算力网络并进行贡献结算，客户端会自动收集以下信息：

| 信息类型 | 具体内容 | 用途 |
|---------|---------|------|
| 硬件配置 | CPU 核心数、总内存大小、GPU 型号与显存大小、操作系统类型与版本 | 评估节点算力等级，匹配合适的训练任务 |
| 节点状态 | 节点在线/离线状态、当前任务执行进度、资源占用率 | 调度中心实时掌握节点可用性，分配任务 |
| 网络信息 | 公网 IP 地址（仅用于连接调度中心，不存储） | 建立客户端与调度中心的通信连接 |
| 贡献记录 | 完成任务数量、贡献值、信誉分 | 按贡献分配社区权益，维护公平的贡献体系 |

### 1.2 任务执行数据

当你领取并执行训练任务时，客户端会下载任务包（包含数据分片和训练配置），并在本地执行训练。此过程中：

- **任务包数据**仅存储在本地内存和临时目录中，训练完成后可按配置自动清理
- **训练结果**（LoRA 权重文件、训练日志、指标数据）会上传到调度中心指定的对象存储
- **我们不收集**：你的个人文件、浏览器历史、聊天记录、密码、信用卡信息等任何与任务无关的数据

### 1.3 账户信息

当你注册萤火虫账户时，我们会收集：

- 用户名
- 密码（经过 bcrypt 哈希加密存储，我们无法获知明文密码）
- 注册时间

---

## 2. 我们如何使用信息

收集的信息仅用于以下目的：

- **算力调度**：根据硬件配置和节点状态，匹配合适的训练任务
- **贡献结算**：根据任务完成情况，计算并记录贡献值
- **社区治理**：根据贡献值分配社区权益（如投票权、优先体验权）
- **系统优化**：分析节点性能和任务完成质量，持续改进调度算法
- **安全保障**：检测异常行为和作弊行为，维护网络健康

我们**不会**将你的信息用于：

- 广告投放或用户画像
- 出售或出租给第三方
- 与项目运营无关的任何商业目的

---

## 3. 信息的存储与保护

### 3.1 存储位置

- 用户账户信息和贡献记录存储在调度中心的 PostgreSQL 数据库中
- 任务结果文件存储在 MinIO 对象存储中
- 所有服务器位于中国上海

### 3.2 数据保留期限

| 数据类型 | 保留期限 |
|---------|---------|
| 用户账户信息 | 账户存续期间 |
| 贡献流水记录 | 永久保留（区块链式不可篡改） |
| 任务结果文件 | 模型聚合完成后 30 天自动清理 |
| 客户端日志 | 本地保留 7 天，不上传服务器 |

### 3.3 安全措施

- 所有通信均通过 HTTPS/TLS 加密
- 密码使用 bcrypt 哈希存储
- 数据库访问受防火墙和认证保护
- 对象存储使用预签名 URL，限制访问时效和范围
- 定期安全审计和漏洞扫描

---

## 4. 数据共享与披露

我们**不会**向任何第三方出售或分享你的个人信息，以下情况除外：

- **法律要求**：当法律法规、法院命令或政府机关依法要求时
- **权利保护**：为保护萤火虫项目、用户或公众的权利、财产或安全时
- **聚合数据**：我们可能会发布匿名的聚合统计数据（如总算力、节点总数），这些数据无法追溯到个人

## 6. 儿童隐私

萤火虫项目不面向 14 周岁以下的儿童。如果我们发现无意中收集了儿童的个人信息，将立即删除。
