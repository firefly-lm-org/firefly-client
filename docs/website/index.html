Firefly LM

300 块月费维持的调度中心，协调全球志愿算力做持续垂直微调。

代码免费 (MIT) · 本机训练 · 权重归你 · 数据不出本机

开始使用 v0.6 已发布

萤火虫不是在从零训练大模型。 萤火虫让闲置 GPU 持续贡献 LoRA 微调适配器，通过 FedAvg 聚合成社区共享的领域模型。 大厂提供通用底座（Qwen3），萤火虫做持续垂直微调（法律、医疗、教育等）。 两者是互补关系，不是替代关系。

代码免费，服务收费；本机训练，权重归你。 社区线开源做公共品，Studio 线做本机训练 + 云端卡片。 你的数据始终在你本机，只回传脱敏信号（任务 ID + Loss + 样本数），不传原始数据。

当前状态 · v0.6

  • ✅ 调度中心：FastAPI + SQLite + MinIO，阿里云在线，19 条路由（含 contrib_signal + aggregated）

  • ✅ 客户端 CLI：train-local / chat / fed 子命令组（claim/train/complete/download/status）
  • ✅ 联邦聚合：FedAvg 等权 + 加权，392 tensors / 18MB / F16，4 题推理全对
  • ✅ 信号回流：幂等写入，脱敏信号，自动更新信誉分
  • 🔄 下一步 v0.7：PyPI 包发布 + 真实多节点联调 + 自动任务生成
