# 萤火虫大模型 Firefly LM — 估值解锁条件清单

> 本文档是 `GOVERNANCE.md` 的附录，定义每个版本阶段从"纸面估值"跃迁到"真实可成交估值"必须满足的客观条件。
>
> 目的：让核心贡献者、潜在投资人、赞助方在同一张表上对账，避免"按 v0.1 叙事给 v1.0 价钱"或"按流量吹估值"。
>
> 原则：**版本号不等于估值，三项硬指标同时过坎才解锁。缺一项，估值砍半。**

---

## 估值计算逻辑说明

萤火虫的估值锚不是"训练出多大模型"，而是三个独立可验证的资产：

| 资产维度 | 衡量指标 | 为什么值钱 |
|---|---|---|
| **节点网络** | 活跃节点数、留存率、独立 GPU 节点占比 | 持续产出可聚合 LoRA 的活水，是项目核心壁垒 |
| **模型质量** | 第三方评测、领域 SOTA、消融实验 | 证明聚合出来的东西"真的能用、比底座好" |
| **商业收入** | ARR、企业合同、基金会资助到账 | 证明有人愿意为它付钱，不是自嗨 |

**公式（定性版）**：

```
估值 = 叙事稀缺溢价 × min(节点分, 模型分, 收入分)
```

三项取**最小值**做乘数——任何一项短板都会把估值拉下来，不存在"用长板补短板"。

## v0.1 微光版（当前阶段 ✅ 全解锁）

### 纸面估值区间：¥120 ~ 300 万

> 非技术创始人 + AI 辅助 + 单人 Bus Factor=1 的折损已计入上限。全解锁后取中上沿约 ¥180~300 万。

### 解锁条件（满足全部 = 上限 300 万；缺一项 = 砍半）

| # | 条件 | 验证方式 | 状态 |
|---|---|---|---|
| 1 | 调度闭环全链路跑通（注册→领任务→执行→提交→结算） | 冒烟测试 10/10 通过 + curl 实跑录屏 | ✅ 已完成 |
| 2 | 聚合 Worker 可触发、产出可读 AggregationRecord | 日志 + MinIO 中有 agg zip + SHA256 可校验 | ✅ 已完成 |
| 3 | 客户端 42/42 测试通过 + 可打包分发 | CI 绿 + PyInstaller 产出可执行文件 | ✅ 已完成 |
| 4 | 官网可访问 + PRIVACY.md + MODEL_LICENSE.md 公开 | `https://firefly-lm.com` 可打开 + 文档仓库根目录可访问 | ✅ 已完成（2026-07-25，Vercel 部署 + 阿里云 DNS 解析 + vercel.json 安全头生效） |
| 5 | 代码版权清晰（所有贡献者签 DCO/CLA） | 仓库有 CONTRIBUTING.md + DCO Signed-off-by 流程 + 已签名单 | ✅ 已完成（v0.1 采用 DCO 机制，ICLA/CCLA 留待 v0.5 升级） |
| 6 | 商标查询记录存档（中英文，证明未撞车） | docs 仓库有 `TRADEMARK_SEARCH.md`，含 CNIPA + USPTO 搜索结果 | ✅ 已完成（框架已建，搜索结果归档中） |

### v0.1 全解锁结论

- **6/6 条件全部满足**，v0.1 估值锚定为 **¥180~300 万**（非技术创始人折损后的中上沿）
- 若未来补完 ICLA/CCLA + 商标正式提交申请，可进一步锚定上沿 ¥250~300 万
- 若 Core 组补到 3 人（C1 系统 + C2 训练 + C3 治理），估值可上浮 20~30%

### 关键约束
- **v0.1 阶段禁止融资**。最多接受捐赠/资源赞助（云厂商捐 OSS、硬件厂捐机器）。
- 若有人出价 > ¥300 万，必是看中"你这个人"而非项目资产，谈的是 acqui-hire，不是项目投资。
- 任何交易不得包含：节点网络、贡献值、聚合记录共识。

### 估值跳档门槛（v0.1 → v0.5）
- 真实 QLoRA 跑通 + 节点破 100 且月留存 >40% + 第一份独立评测证明聚合 LoRA 比随机初始化好
- Core 组 ≥ 3 人（C1/C2/C3 齐全）
- 商标在中美至少一国提交申请

## 投资/收购方的统一应答话术

当外部资本表示兴趣时，按以下顺序回应，避免被低价收割：

### 第一句：确认对方想买什么
> "请问您感兴趣的是商业服务公司的股权，还是非营利侧的代码/商标/社区？这两者是分开的，我们先对齐。"

### 第二句：亮出不可交易资产
> "节点网络、贡献值、聚合记录属于社区公共资产，不在任何交易范围内。这部分会写进 GOVERNANCE 和所有合同。"

### 第三句：用本清单对账
> "我们每个版本的估值有公开解锁条件清单（VALUATION_GATES.md）。如果贵方给出的价格，对照清单条件，我们可以一起逐条核对。"

### 第四句：划三条红线
> "有三条永远不谈：① 闭源 ② 贡献值代币化 ③ 把节点当免费标注工。这三条任意一条出现，合作终止。"
