# 火种学生创业合作政策

> 火种是基础设施，不是内容方。这份文档说清楚：学生能做什么、我们做什么、怎么合作、什么不能碰。

---

## 一、大学生用火种创业的 5 个方向

每个方向都标注了门槛、收入模型、火种角色。

### 方向 1：垂直考点 LoRA 单品（单人，最低门槛）

| 维度 | 说明 |
|------|------|
| 适合人群 | 师范类大三学生，熟悉本省高考/教资题库 |
| 做法 | 整理 200 条高考题解析 → `firefly-node train-local` → 挂闲鱼/小红书卖 ¥9.9 |
| 收入模型 | 本校 3000 人 × 1% 转化率 × ¥9.9 = ¥297/届，可复制到其他省份 |
| 火种角色 | 训练工具 + 标准格式（买家给 `firefly-node chat` 命令即可用） |
| 门槛 | 最低——一台 GPU 或租 AutoDL ¥1.5/h |

### 方向 2：社团/实验室内部联邦（多人协作）

| 维度 | 说明 |
|------|------|
| 适合人群 | 计算机系 + 外语系组队（4 人） |
| 做法 | 各自整理 50 条数据，分别 `train-local`，本地 mock 聚合出统一适配器 |
| 收入模型 | 全校留学群卖"雅思写作批改 LoRA 会员" ¥29.9/月 |
| 火种角色 | 联邦叙事变成卖点——"4 个人数据没出过自己电脑，但模型是一起训的" |
| 成本 | 0 服务器费（可用本地 mock 聚合或公有调度中心） |

### 方向 3：毕业设计 + 小产品打包（学术变现）

| 维度 | 说明 |
|------|------|
| 适合人群 | 大四学生 |
| 做法 | 毕设用火种跑 law/medical 实验（对比等权 vs 软加权），答辩后把成果整理成产品 |
| 收入模型 | 法学院贴海报卖 ¥19.9 + GitHub 开源赚 star |
| 火种角色 | 实验平台 + 防作弊/信誉分可写进论文 |
| 价值 | 毕设拿优 + 赚几百块 + GitHub 简历资产 |

### 方向 4：机构寒假集训营助教工具（B 小 B）

| 维度 | 说明 |
|------|------|
| 适合人群 | 在校生兼职某培训机构助教 |
| 做法 | 说服机构"5 个分校题库聚合，数据不出分校"，在机构内网跑火种 |
| 收入模型 | 部署费 ¥3000 + ¥500/月维护 |
| 火种角色 | "联邦"是机构听懂的语言——"数据不出分校，模型比单分校强" |
| 风险 | 机构数据合规由学生签保密协议，与火种项目无关 |

### 方向 5：交叉语言教育（中英双语）

| 维度 | 说明 |
|------|------|
| 适合人群 | 外语 + CS 双学位 |
| 做法 | 训 `english_grammar.safetensors`，在留学生社群卖 ¥14.9，同时挂 HuggingFace |
| 收入模型 | 国内 ¥14.9/份 + 海外 HuggingFace 曝光 |
| 火种角色 | 中英双语域天然适合火种"全球节点"叙事 |
| 亮点 | 国内卷完可以卖海外，火种不锁区域 |

## 二、我方角色定位（三档）

### 档 A：只做基础设施（当前执行）

| 做什么 | 不做什么 |
|--------|---------|
| 调度中心 + CLI + 信誉分 | 不训具体领域适配器 |
| 防作弊 + demo 模式 | 不卖给学生 |
| 开源代码 + 文档 | 不碰机构客户 |

收入来源：爱发电月付 + 未来 v0.7 企业版授权。

### 档 B：做一个官方示范品（必须做）

用现有 law 域聚合权重，包装成"火种官方示范：法律劳动纠纷 LoRA"，免费开放下载。

目的：证明"火种训出来的东西能用"，给学生一个信任锚——"官方都训出来了，我训的也不会差"。

这是营销资产，不是商品。

### 档 C：自己下场做教育 SaaS（不建议现在做）

做"火种辅导"网站卖 ¥9.9/月订阅。

**不做的原因**：这是 Studio 轨的事，v0.8 以后再说。现在做等于把教育飞轮第 4 圈提前到第 1 圈，重资产、和种子用户抢市场。

**结论：我方做 A + B，不做 C。**

## 三、和大学生创业者的 4 种合作模式

### 模式 1：纯生态（最推荐，零合同）

| 维度 | 说明 |
|------|------|
| 合作方式 | 学生自己训、自己卖、自己担责 |
| 我方参与 | 文档列"社区案例"：某学生用火种做了 X 卖了 Y 份 |
| 学生义务 | 自愿在适配器 manifest 留 `"framework": "firefly-lm"` |
| 成本 / 收益 | 成本 0；收益：火种被引用次数↑，爱发电赞助者↑ |

### 模式 2：信誉分联动（轻合作）

| 维度 | 说明 |
|------|------|
| 合作方式 | 学生回传信号到公有调度中心（106.14.220.169），涨自己信誉分 |
| 我方参与 | 信誉分 ≥ 50 的学生，官网"贡献者榜"挂名 + 适配器 manifest 在 `benchmarks/community/` 子目录收录 |
| 边界 | 不分成、不担保效果、不存原始适配器文件（只存 manifest 链接，避免版权/合规） |
| 价值 | 学生多"官方认证贡献者"头衔，我方多生态内容 |

### 模式 3：定向共创（选 2-3 个尖子）

| 维度 | 说明 |
|------|------|
| 合作方式 | 选法律/教育/医疗各 1 个学生团队，给 v0.7 联邦 CLI 早期访问权 |
| 条件 | 训练日志 + holdout 结果回传，允许我方匿名用于博客/论文 |
| 回报 | "火种核心贡献者"署名 + 未来企业版内测资格 |
| 边界 | 口头约定，不签独家，不限制他们同时用其他框架 |

### 模式 4：机构项目转包（谨慎，v0.7 后再碰）

| 维度 | 说明 |
|------|------|
| 合作方式 | 学生接机构部署单，我方远程协助排错 |
| 收费 | 学生合同额的 10-20% 技术支持费，或 ¥200/次远程支持 |
| 边界 | 书面声明——数据合规/交付质量由学生签合同承担，我方只卖"软件使用权+支持" |
| 触发条件 | 等 v0.7 联邦 CLI 真通后再做，现在不接 |

## 四、红线（写进任何合作前）

| # | 红线 | 原因 |
|---|------|------|
| 1 | **不碰学生原始数据** | 火种设计就是不碰，合作时更不能直接收学生/机构的题库 |
| 2 | **不担保适配器效果** | `firefly-node verify` 只验证"来自火种+未被篡改"，不验证"答对率 90%" |
| 3 | **不签独家** | 学生可同时用 Llama-Factory、MS-Swift，火种只是选项之一 |
| 4 | **品牌隔离** | 学生产品叫"高考物理辅导 LoRA by 张三"，不是"火种出品" |
| 5 | **合规兜底在学生** | 机构项目让学生和机构签数据处理协议，我方不进合同 |

## 六、学生创业者的完整路径

```
学习（demo + Day1/Day2 文档）
  ↓
训练自己的适配器（firefly-node train-local）
  ↓
验证效果（firefly-node chat / firefly-node verify）
  ↓
发布销售（爱发电 / 淘宝 / 知识星球 / GitHub）
  ↓
回传信号涨信誉分（模式 2）
  ↓
成为定向共创者（模式 3，可选）
  ↓
接机构项目（模式 4，v0.7 后）
```
